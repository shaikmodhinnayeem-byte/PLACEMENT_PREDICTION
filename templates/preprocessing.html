Min-Max Normalization (Feature Scaling to [0, 1])

Min-Max Normalization rescales numeric attributes into a fixed bound between 0 and 1 using the formula below. This is especially vital for distance-based algorithms like K-Means Clustering and DBSCAN where scale disparities can distort Euclidean distance.

Mathematical Formula:

X_norm = (X - X_min) / (X_max - X_min)
